# ESP32 Portable GPS Speedometer PCB

A compact *70.0 mm × 47.5 mm, 2-layer custom PCB designed in **KiCad* for a portable GPS speedometer built around a *30-pin ESP32 DevKit*.

## Hardware Components
* *Microcontroller:* 30-pin ESP32 DevKit (custom KiCad footprint)
* *GPS Receiver:* UART GPS Module (RX2 / TX2)
* *Display:* 0.96" I2C OLED Display (SDA / SCL)
* *User Controls:* Rotary Encoder Module + Tactile Push Button
